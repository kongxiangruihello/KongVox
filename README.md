# KongVox 0.12.0

本机转写核对（2026-10-08）：

- **疑似漏读 / 重读检查**：「成品交付检查」新增「本机转写核对」，用 Mac 自带的语音识别（macOS 26 起）逐段转写已生成的配音，按读音（无声调拼音）与送去合成的文本比对；同一处相差 2 个音节以上即提示，并可「定位试听」。古文生僻字被识别成同音常用字不算错误。音频不上传、不计费；转写结果按版本缓存，再次核对只处理新版本。
- **本机语音识别字幕对齐**：字幕「时间对齐」新增第三种模式，用识别到的逐字时间确定分句、竖屏字幕的起点；未转写的片段仍按字数分配，段落字幕不受影响。
- **修复**：0.11.x 起，0.11 之前生成的音频会被误判为「待更新」并提示重新合成（计费）；现已按原设置识别为可复用。
- 需要 macOS 26 或更高版本及支持的 Mac；不满足时该功能隐藏，其余功能照常。

## 0.11.3


代码审查修复版：

- **手工字幕过期不再卡死**：字幕编辑器始终按当前音频生成自动草稿，可核对后覆盖旧字幕；交付检查和字幕设置新增「清除手工字幕」。「恢复自动字幕」现在恢复的是真正的自动字幕。
- **本地停顿对齐**：只在同一片段内的分句边界前后 0.4 秒寻找明显停顿，片段之间的边界和停顿保持不变；单独 SRT、ZIP、批量与短视频导出统一使用这一设置。
- **就绪判定统一**：交付检查、批量导出、接缝试听、完成度与队列估算都与主界面使用同一规则（含前后句语气参考）。
- **长文性能**：输入与滑杆改为停顿约 0.8 秒后保存（退出时立即保存）；项目版本移到 `Versions/` 目录单独存放，旧项目首次启动时自动迁移；播放进度单独刷新，不再每秒重绘整个界面 20 次。
- **整理磁盘**：新增删除项目（侧栏右键或「项目备份与整理」菜单）和「清理未引用音频」，只删除不属于任何项目、归档片段或已保存版本的音频。
- 接缝试听包含接缝淡化；接缝渲染改为逐段流式写出；短视频交付包先在临时目录生成再整体移入，标题中的 `/` 等字符会被替换，ASS 字幕转义 `{}` 与 `\`。
- 中文旧文本支持 GB18030/GBK 编码；日期读法预览可识别紧跟汉字的日期；MP3 转换失败时显示 FFmpeg 的错误原因；删除段落前确认。
- 版本号统一由 `version.env` 提供。打包时可设置 `CODESIGN_IDENTITY` 使用固定签名身份，避免每次升级后重新授权钥匙串。

## 0.11：上下文重做、批量预算与短视频交付

本版新增前后句语气参考重做、字幕本地停顿辅助、项目版本回滚、批量预算拦截、接缝淡化，以及包含 WAV、SRT、ASS、项目清单和标题页素材的竖屏短视频交付包。

从侧栏「长文精修 / 音色收藏」或「成品交付检查」进入：

- **上下文与局部精修**：普通长文继续按自然段和服务长度分批，单独拆分需要修正的段落时，其他段落的音频保持复用。生成范围会列出新请求、恢复下载、可复用和未选择的字数；接缝可循环试听前后各最多 3 秒，包含停顿和统一音量处理。
- **字幕编辑器**：在当前音频时间轴上修改字幕文字和入出点，支持拆条、合并、单条循环试听和恢复自动字幕。手工字幕会写入项目，音频、文稿、声音或样式改变后自动标记过期，保存前需要重新核对。
- **词典命中预览**：词典条目可标记人名、地名、品牌、多音字或其他，并可停用；生成前预览本篇实际命中的替换，显示项目词条优先、长词优先的结果。
- **成品交付检查**：集中检查缺失/待更新片段、未采用候选版本、音频规则提示、总时长和字幕状态。确认后才可导出 WAV、M4A、MP3、SRT 或音频字幕 ZIP。

本版通过 65 组本地/模拟测试和独立项目界面检查，没有新增付费 API 调用。字幕时间仍是分句或字数分配，不是语音识别逐字对齐；交付检查也不能自动判定漏读。

## 0.9：长文按句精修

从侧栏「长文精修 / 音色收藏」进入：

- **读音、语速与停顿**：逐句填写完整替代读法，原稿与字幕保留；可单独设置语速和句后停顿。数字、日期、英文缩写提供规则读法预览，经确认才填入；多音字仍需人工修正。只改停顿不重新合成，改读法或语速则生成候选版本，再选择采用。
- **缩小重做范围**：手动开启「按句精修」后，修改一句可保留其他未变化句子的音频，生成前显示待合成和可复用字数。超长句仍按服务限制拆分。旧项目默认保持原有分批方式；开启按句精修可能使原整段音频需要重新生成并计费，旧音频保留在历史中。已有单段精修的项目需先处理这些设置再切换，避免静默丢失。
- **字幕样式**：保留原有段落字幕，新增分句字幕、每行最多 16 字且最多两行的竖屏字幕。单独 SRT、ZIP 和批量交付使用同一设置。片段起止来自实际音频，片段内部按字数分配时间，未接入语音识别，剪辑时仍需核对入点。
- **音色收藏与对比**：保存中文昵称和用途标签，最多选两个收藏，用同一段文稿生成试听；生成前提示费用，相同设置和文稿复用本地试听缓存。收藏不包含密钥和词典，试听不替换项目的成品音频。
- **长文完成度**：核对当前文稿的开头、结尾、章节和本地音频是否就绪，结合原有静音、音量及时长检查定位问题。不推断未导入的章节，不自动判定漏读或重复朗读。
- **生成前检查**：本地检查服务地址、模型、音色、长度、语速以及已存密钥是否可读取；先构造待生成请求，避免可提前发现的配置问题产生部分合成。检查不调用付费接口，不能证明账户权限、额度或远端服务可用。

按句生成的语气衔接取决于服务，建议先用短稿试听。0.9 通过 58 组本地/模拟测试和独立项目界面检查，本轮没有新增付费 API 调用。火山引擎等已有服务继续保留。

## 0.8：批量长文与火山引擎

从侧栏「文稿导入 / 批量工作台」进入：

- **文稿导入**：TXT、Markdown、DOCX，可多选并预览全文；每份文件创建独立长文项目。可略过网址和 Markdown 脚注。Word 读取正文与可识别标题，不保留排版、图片、页眉或脚注正文。单文件最多 20 MB / 20 万字，一次最多 30 份。
- **生成队列**：跨项目按顺序生成，显示所选服务与待处理字数，支持上下调整、失败时停止或继续其他项目、片段后暂停和跳过。开始前确认一次；失败不自动重试，重启后手动继续。再次开始会重新检查全部队列，复用已完成且未修改的音频。取消不能撤销已发生的服务费用。
- **配音预设**：保存服务、音色、语速、表达要求、停顿与音量设置，用于当前或新项目；不含密钥和词典。服务配置改变后需重新保存预设。
- **批量交付**：多选项目，按整篇或按章导出 WAV + SRT + 交付清单；名称包含顺序编号，字幕与音频使用相同时间轴。任何项目未就绪或导出失败时，不留下半份交付目录，也不覆盖已有文件夹。
- **长文验收**：真实 CosyVoice v3-flash 合成 1854 字，16 个处理片段，完整音频 416.77 秒。已验证暂停、重新加载、续做不重复生成、完整 WAV/SRT 导出；本地规则检查无提示，仍建议人工复听漏读及听感。

### 火山引擎 豆包语音

服务设置已内置「火山引擎 豆包语音」。填写新版控制台 **API Key**，默认资源 ID `seed-tts-2.0`、VV 音色 `zh_female_vv_uranus_bigtts`。也可选 1.0 资源并填写对应声音 ID。资源、音色和账户权限需匹配；本版不支持旧 AppID + Token 或云 AccessKey/SecretKey。密钥仍存放在钥匙串。

采用官方 V3 单向 SSE 合成接口，按顺序拼接 24 kHz PCM，仅在完整结束后保存音频；拒绝截断流和错误事件。本版支持语速，不发送表达指令，不提供实时边合成边播放。中断后重新请求可能再次计费。当前仅做模拟验证，未使用真实火山账户合成。

接口依据：[火山引擎官方文档](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)、[字节跳动官方示例](https://github.com/bytedance/agentkit-samples/blob/main/skills/byted-text-to-speech/scripts/text_to_speech.py)。

本次真实验收获授权上限 2 元；按 [CosyVoice v3-flash 北京地域官方价格](https://help.aliyun.com/zh/model-studio/cosyvoice-v3-flash) 1 元/万字符估算，提交正文 1824 字符约 0.1824 元；暂停续做前重复预留但未重复发送的预算计入保守上界 0.3645 元。实际账单以服务商为准。验收文稿与音频仅保存本地，不提交仓库。

## 0.7：长文成品检查

- **文稿跟随播放**：侧栏「成品检查 / 对比」打开复听页。点击片段，从对应位置播放全文；当前片段高亮并可自动滚动。播放、字幕使用同一裁剪与停顿时间轴，精度为片段级，不是逐字对齐。
- **问题定位与修复**：在成品页运行质量检查，原文旁显示规则提示并可复听；「修复 / 版本对比」填写完整替代读法，保持原文及字幕不变。生成请求仍按服务商实际计费。
- **先对比再采用**：从修复页生成的新版本保留为候选，不自动替换已采用音频。可分别试听新旧版本，点击采用才用于成品。旧文稿/声音设置下的版本可以试听，但须恢复对应设置才能采用。修改了读法却未采用匹配音频时，完整导出保持禁用。
- **项目备份恢复**：侧栏「项目备份」导出 `.kongvox` 文件，包含文稿、词典快照、声音设置、当前及归档片段的历史音频。恢复先校验，再创建新项目和新音频文件名；原项目不覆盖。备份不含钥匙串 API 密钥、下载缓存链接或服务目录。恢复项目保留原全局词典快照，当前全局词典修改不会改变它；继续生成前需核对或重新配置服务。
- **长文性能**：缓存用量估计，避免播放进度刷新反复拆分全文；字幕时间轴计算放到后台。备份以 1 MB 数据块读写，音频合并逐片段处理。已用一万字和三万字模拟文稿验证编辑、暂停/重启续做及完整合并，另验证 20 分钟 PCM 输出。

备份为未加密的本地文件；如历史音频缺失则停止备份，不悄悄忽略。当前上限为单音频 256 MB、音频总量 8 GB、项目记录 32 MB。不要将备份当作可公开分享的文件；它包含完整文稿与音频。真实云端合成速度、长文发音完整性和主观音质仍需使用所选服务验收。

## 0.6：长文稳定与精修

从侧栏「长文工作台 / 任务」进入新功能：

- **章节**：识别独立行的「第一章」、数字编号、Markdown 标题；没有标题时作为正文一章。点击更新处理片段后，可按章生成待更新内容、试听、导出 WAV，或在生成范围中勾选整章重做。旧音频保留在历史中。标题也会朗读；全文合并导出继续可用。
- **局部重做与范围预览**：长文修改后优先用原片段作为匹配锚点，避免插入一句就挪动所有后续分段。生成前列出复用、恢复下载和待生成内容。更改发生在某片段内部时，仍可能重做整片段，不是逐词音频编辑。
- **发音词典**：支持当前项目和所有项目两种范围。同名词条使用项目规则，同位置优先匹配长词，不连锁替换。字幕保留原文；只让朗读文本实际改变的音频待更新。替换后超出服务长度限制会在请求前拦截。切换词典范围或关闭编辑前请保存。
- **质量检查**：在本地检查未生成/过期音频、文件缺失、至少 1.5 秒近静音、相邻片段原始音量差超过 8 dB，以及异常短时长。可定位到片段试听。这是规则提示，不是语音识别或漏读判定；统一音量后的最终效果仍需复听。
- **任务中心**：显示各项目片段进度与失败诊断，提供恢复入口。支持当前片段保存后暂停，也可立即取消。重启后手动继续，已完成且未变化的内容复用；没有跨项目自动付费队列。

全局词典保存于本机 `dictionary.json`，项目词典和任务状态随项目保存。本次升级不上传用户项目、音频或密钥。

## 0.5：长文配音与完整交付

1. **自然衔接与统一音量**：人工分批处不再插入段落停顿，真实自然段保留所选停顿；人工接缝最多裁去每侧 200ms 静音并淡入淡出 5ms。默认进行有限幅度的 RMS 音量匹配，可关闭，不改写原始音频。服务产生的语气差异仍需试听确认。
2. **先听开头**：新分段优先生成不超过 120 字的开头，试听最多 20 秒；继续全文时复用已生成片段。旧项目保持已有片段以减少重新计费。
3. **完整播放进度**：显示已播放与总时长，可拖动定位、前后跳转 10 秒。
4. **音频与字幕一起导出**：一键导出包含 WAV 与 SRT 的 ZIP；两者使用相同的裁剪、停顿时间轴。字幕按内部处理片段分条，不是逐字对齐。
5. **用量提示与完成通知**：显示全文、待生成、可复用及待恢复下载的字符数；不是服务商费用报价。可主动开启全文完成通知，需要 macOS 允许通知。

新增应用图标、首次启动使用引导（侧栏可再次打开），以及带拖拽说明的 DMG 安装界面。[图标与生成提示词](Assets/ICON-PROMPT.md)。

## 0.4：长文模式

默认以完整文章编辑，不再要求手动「添加为配音段落」。粘贴全文 → 点击「生成全文」→ 完成后试听或「导出完整音频」。WAV/M4A 导出自动合并全文；MP3 仍需 FFmpeg。

- 文章原样保留，服务长度限制由后台分段处理：Qwen 最多 500 字，其他服务最多 700 字。服务仍按实际 API 使用计费。
- 显示全文进度，生成失败或关闭后重新点击「生成全文」继续；未变化的处理片段保留原有音频、历史与下载恢复标识。
- 修改全文后禁用旧音频的完整试听和导出，更新生成后恢复。字幕也遵循同一校验。
- 「段落精调」保留发音替代文本、单段重做、历史选择及下载缓存操作。切回长文时合并精调后的文本。
- 旧项目默认以全文展示，已有段落与待添加草稿均保留；全新字段为可选，旧项目可以直接读取。重新分段时未使用的段落历史保留在项目内，不删除对应音频。
- 保留精确匹配的片段以减少重做；修改导致分段边界变化时，受影响片段仍需重新生成。

## 0.3.1：修复实际 CosyVoice 返回格式，加入 Qwen-TTS

- 已用两份实际失败缓存定位：24 kHz 单声道 PCM16 的 RIFF/data 长度分别为 `0x7fffffbf` / `0x7fffff9b`，是未回填的流式占位长度。本版仅识别此确定的配对格式，继续拒绝一般截断文件。原有失败缓存可直接继续处理，无需放弃缓存重新合成。
- 新增「阿里云 Qwen-TTS」服务，支持 `qwen3-tts-flash` 和 `qwen3-tts-instruct-flash`。默认 Cherry 音色，需在新服务中保存百炼北京地域 API Key，旧密钥不会自动复制。
- 服务设置统一提供「选择模型预设」，CosyVoice 可选 v3-flash / v3-plus；也可手填其他兼容模型。当前 CosyVoice v3-plus 适配仅发送文本、音色、格式和语速，不发送表达指令。
- Qwen 标准 Flash 不应用表达和语速设置；Instruct Flash 通过自然语言提示表达和语速，不保证精确倍速。每段最多 600 字；选用 Qwen 后，新导入文稿按最多 500 字拆分，已有超长段落需手工拆分。支持北京域名音频下载及失败缓存恢复。
- 新增服务不改变已有项目或默认服务。Qwen 模型可用性需由实际账户验证。

接口与声音依据：[Qwen-TTS 官方接口](https://help.aliyun.com/en/model-studio/qwen-tts-api)、[CosyVoice 音色列表](https://help.aliyun.com/en/model-studio/cosyvoice-voice-list)。

## 0.3：恢复下载、服务诊断、字幕导出

- **CosyVoice 恢复下载**：服务返回成功的音频链接后，先保存到本地，再下载。下载失败、取消或重启后，相同段落/试听文本和设置会继续下载，不再次合成。下载完成但解码失败时，保留原始 WAV 供再次处理。项目音频和记录成功保存后清除对应缓存。
- **明确错误与诊断**：区分密钥、权限、模型/音色配置、额度、频率限制、网络、下载和音频格式问题。服务试听和生成失败支持复制诊断，诊断仅含阶段、分类、HTTP 状态及建议，不含文稿、密钥、服务响应正文或签名链接。部分服务仅返回 429 时无法精确区分限流和额度。
- **SRT 段落字幕**：在「导出音频 → SRT · 段落字幕」单独保存字幕，再导出相同项目的完整音频。字幕使用原文（不是发音替代文本），按实际音频帧数及当前段间停顿计算时间。每个段落一条字幕，不是逐字或逐句语音对齐；修改段落、音频版本或停顿后需要重新导出。

恢复缓存位于本机 Application Support/KongVox/Recovery，不写入项目 JSON 或 Git 仓库。链接过期或缓存音频持续异常时，可在段落/服务试听处选择「放弃下载缓存」，确认后再次生成；重新合成可能计费。修改文稿或声音设置会使用另一份缓存。旧版失败的请求没有保存链接，不能追溯恢复。OpenAI/Gemini 直接返回音频，本版没有为其实现远端任务恢复。

## 0.2.1：阿里云 CosyVoice

已加入阿里云百炼 CosyVoice 原生 HTTP 接口。升级后自动补充服务入口，不改变现有默认服务或项目选择。

1. 打开「服务设置 → 阿里云 CosyVoice」。
2. 填入**阿里云百炼北京地域 API Key**（不是阿里云 AccessKey，也不是智能语音交互产品的临时 Token）。

应用请求 24 kHz WAV，收到成功结果后立即通过 HTTPS 下载到本地。下载请求不携带 API Key。合成成功且链接已保存后，可继续下载；放弃缓存后重新合成可能再次计费。未进行真实 CosyVoice 付费调用，账户权限及实际音质需你自行试听。

## 配置 Gemini

1. 打开「服务设置」，选择左侧 **Gemini**。
2. 从 [Google AI Studio](https://aistudio.google.com/apikey) 获取 API Key，填入密钥框。`gen-lang-client-…` 是项目 ID，不能用作密钥。
3. 默认基础地址为 `https://generativelanguage.googleapis.com/v1beta`，模型为 `gemini-3.8-flash-tts`。也可选择其他内置 TTS 模型或输入模型 ID，实际可用性取决于账户和服务商。
4. 点击「测试并试听」，确认声音后「保存服务」。试听不会自动保存配置。
5. 返回主窗口，在「声音工作台 → 配音服务」选择 Gemini。旧项目保持原服务，不会自动切换。

Gemini 3.8 使用独立的表达风格字段，较早预览模型使用朗读提示。Gemini 的语速设置是表达目标，不保证精确倍速。应用将 WAV 或带正确格式声明的 PCM 统一为 24 kHz、单声道、16-bit PCM，再用于播放和导出。

## 添加其他 API

在「服务设置 → 添加服务」选择 Gemini 原生或 OpenAI 兼容 API。填写 HTTPS 基础地址（不含最终 `/audio/speech` 或 `/models/…:generateContent` 路径）、模型和声音列表。声音 ID 用逗号分隔。

OpenAI 兼容服务需支持 `/audio/speech` 的请求格式，并返回 24 kHz、单声道、16-bit little-endian PCM 或 WAV。并非任意语音 API 都兼容。API Key 留空保留同一地址的已存密钥，勾选清除选项后保存可删除该地址的密钥。

修改服务配置不会悄悄改变已有项目。需要在项目内点击「应用最新服务配置」。改变服务、模型、声音或文稿后，过期音频会标记为待更新，并阻止导出。历史音频不删除。

删除被项目使用的服务前，需先切换对应项目；也可停用。删除配置不自动删除钥匙串条目，需清除密钥时先在该服务中勾选清除并保存。

## 配音流程

粘贴完整文稿 → 先听开头 → 生成全文 → 完整试听 → 导出音频与字幕。

- 按自然段拆分，过长段落按句子边界拆分；支持独立发音替代文本。
- 单段重做、历史版本、顺序生成、取消、失败后继续。
- 项目自动保存，全文试听与暂停、段间停顿。
- WAV / M4A 导出；可选 MP3 需要本机 `/opt/homebrew/bin/ffmpeg` 或 `/usr/local/bin/ffmpeg`。
- 播放已有音频、切换历史版本和本地导出不调用生成接口。
